MATERIAL DE APOIO

Principais tags HTML em um só lugar.

Consulte o significado, a melhor situação para uso e um exemplo simples de cada elemento.

01

Estrutura e semântica

<html>

Documento HTML

É o elemento raiz: envolve todo o conteúdo da página.

<html lang="pt-BR">...</html>
<head>

Metadados

Guarda informações da página, como título, codificação e links para CSS.

<title>Minha página</title>
<body>

Conteúdo visível

Contém tudo o que aparece para quem visita o site.

<body>Conteúdo</body>
<header>

Cabeçalho

Área introdutória da página ou de uma seção; pode ter logo e menu.

<header>Meu site</header>
<nav>

Navegação

Agrupa links de navegação importantes.

<nav><a href="#">Início</a></nav>
<main>

Conteúdo principal

Representa o conteúdo único da página. Use apenas um por página.

<main>...</main>
<section>

Seção temática

Divide conteúdos por assunto; normalmente deve ter um título.

<section><h2>Sobre</h2></section>
<article>

Conteúdo independente

Use para um conteúdo que faz sentido sozinho, como um post ou notícia.

<article>Post do blog</article>
<aside>

Conteúdo complementar

Inclui informações relacionadas, porém não essenciais, como uma barra lateral.

<aside>Links úteis</aside>
<footer>

Rodapé

Área final da página ou seção, com contatos e direitos autorais.

<footer>© 2026</footer>
<div>

Agrupamento genérico

Organiza elementos para estilo ou layout quando não há uma tag semântica adequada.

<div class="card">...</div>

02

Texto e conteúdo

<h1> a <h6>

Títulos

Definem a hierarquia dos títulos. Use um único <h1> como título principal.

<h1>Título principal</h1>
<p>

Parágrafo

Representa um bloco de texto comum.

<p>Um parágrafo.</p>
<strong>

Importância

Dá forte importância ao texto; geralmente aparece em negrito.

<strong>Atenção!</strong>
<em>

Ênfase

Destaca uma palavra com ênfase; geralmente aparece em itálico.

<em>muito</em>
<mark>

Marcação

Realça um trecho relevante, parecido com um marca-texto.

<mark>destaque</mark>
<small>

Texto secundário

Exibe observações, direitos autorais ou texto menos importante.

<small>Termos válidos.</small>
<br>

Quebra de linha

Quebra uma linha de texto. Use quando a quebra tiver significado.

Rua A<br>Fortaleza - CE
<hr>

Separação temática

Cria uma divisão entre assuntos diferentes.

<hr>
<ul>, <ol>, <li>

Listas

<ul> cria lista sem ordem e <ol> cria lista numerada; ambas usam <li>.

<ul><li>Item</li></ul>

03

Links e imagens

<a>

Link

Cria um caminho para outra página, parte da página, arquivo ou site.

<a href="contato.html">Contato</a>
<img>

Imagem

Exibe uma imagem. O atributo alt descreve a imagem para acessibilidade.

<img src="foto.jpg" alt="Paisagem">

04

Formulários

<form>

Formulário

Agrupa campos que enviam dados para um destino.

<form action="/enviar">...</form>
<label>

Rótulo de campo

Explica o que deve ser preenchido e melhora a acessibilidade.

<label for="nome">Nome</label>
<input>

Campo de entrada

Recebe dados. O tipo muda seu comportamento: texto, e-mail, senha e mais.

<input id="nome" type="text">
<textarea>

Texto longo

Cria uma área para mensagens e descrições maiores.

<textarea></textarea>
<select>

Seleção

Apresenta opções escolhidas com <option>.

<select><option>Brasil</option></select>
<button>

Botão

Aciona uma ação. Em formulários, defina o atributo type.

<button type="submit">Enviar</button>

05

Tabelas

<table>

Tabela

Organiza dados que possuem relação entre linhas e colunas.

<table>...</table>
<tr>

Linha

Cria uma linha dentro da tabela.

<tr>...</tr>
<th>

Cabeçalho

Define o título de uma coluna ou linha.

<th>Produto</th>
<td>

Célula de dado

Inclui o valor comum em uma tabela.

<td>Notebook</td>
Feito para consulta durante os estudos de HTML.
